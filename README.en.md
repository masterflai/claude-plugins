# Claude Plugins by masterflai

[Deutsch](README.md) · **English**

Plugins for Claude, free to use under the MIT License.

## Plugins

| Plugin | Purpose |
|---|---|
| [`ebuch-barrierefrei`](ebuch-barrierefrei/README.en.md) | Converts teaching material from PowerPoint, Word or PDF into accessible DOCX files following the German E-Buch standard — for learners who use a screen reader or a braille display |

## Installation

In a Claude session, in one step:

```
/plugin install ebuch-barrierefrei --marketplace masterflai/claude-plugins
```

Or add the collection once and then install any plugin from it:

```
/plugin marketplace add masterflai/claude-plugins
/plugin install ebuch-barrierefrei@masterflai-plugins
```

Update with `/plugin update <plugin>@masterflai-plugins`, or turn on automatic updates for this collection.
