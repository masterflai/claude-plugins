# Datenschutzhinweise / Privacy

*English summary below.*

## Datenschutzhinweise für das Plugin „E-Buch barrierefrei"

### Was das Plugin verarbeitet

Das Plugin liest die Dateien, die Sie ihm in einer Claude-Sitzung übergeben – Präsentationen, Word-Dokumente oder PDFs –, um daraus eine barrierefreie Word-Datei zu erzeugen.

Enthalten diese Dateien personenbezogene Daten, etwa Namen, E-Mail-Adressen oder Fotos von Personen, werden auch diese gelesen und können in die erzeugte Datei übernommen werden. Das Plugin sucht nicht gezielt nach solchen Daten und wertet sie nicht aus.

### Was das Plugin nicht tut

- Es **speichert keine Daten** außerhalb der Sitzung. Die erzeugte Datei legen Sie selbst ab, an einem Ort Ihrer Wahl.
- Es **sendet keine Daten** an Dienste außerhalb von Claude. Die mitgelieferten Skripte rufen keine externen Server auf.
- Der **Autor des Plugins erhält keine Daten.** Es gibt keinen Server, keine Telemetrie und kein Tracking.

### Wo die Verarbeitung stattfindet

Die Verarbeitung findet innerhalb von Claude statt, also im Rahmen Ihres Claude-Kontos bei Anthropic. Dafür gelten die Datenschutzbestimmungen von Anthropic und die Einstellungen Ihres Kontos bzw. Ihrer Organisation. Dieses Plugin ändert daran nichts.

### Empfehlung beim Umgang mit personenbezogenen Daten

Bei allgemeinem Unterrichtsmaterial ist die Verarbeitung in der Regel unkritisch. Sobald eine Datei personenbezogene Daten von Lernenden enthält – etwa Leistungsnachweise, Prüfungen oder Gutachten –, klären Sie bitte vorab mit Ihrer Einrichtung, ob die Verarbeitung mit Claude zulässig ist. Im Zweifel entfernen Sie personenbezogene Angaben vor der Übertragung aus der Quelldatei.

### Kontakt

Fragen und Hinweise bitte als Issue im Repository: https://github.com/masterflai/claude-plugins/issues

## Privacy notice (English summary)

- **What it processes:** the files you give it in a Claude session (presentations, Word documents, PDFs). If those files contain personal data such as names, e-mail addresses or photos of people, that data is read and may appear in the generated document.
- **No storage:** the plugin stores nothing outside the session. You save the output yourself.
- **No transmission:** the plugin sends no data to any service outside Claude. Its scripts make no network calls.
- **Nothing reaches the author:** no server, no telemetry, no tracking.
- **Where processing happens:** inside Claude, under your Claude account and Anthropic's privacy terms.
- **Recommendation:** remove personal data of learners from source files before conversion unless your institution permits processing it with Claude.
- **Contact:** https://github.com/masterflai/claude-plugins/issues
